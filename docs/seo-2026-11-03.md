## Dependências e limites

| Item da auditoria | Situação / condição necessária |
| --- | --- |
| Domínio próprio | Exige definição e controle de um domínio e acesso ao DNS. O domínio sugerido no documento é um exemplo, não confirmação de propriedade ou autorização de compra. |
| Migração e redirects 301/308 | Aplicáveis após definir o domínio. O endereço antigo redireciona automaticamente pela hospedagem para o endereço atual verificado. Não foi configurada migração para domínio próprio. |
| Search Console do novo domínio | Depende da migração e verificação da nova propriedade. |
| Perfil da Empresa no Google | A conta disponível está desconectada; a extensão local também não possui contexto de navegador conectado nesta sessão. Nenhuma alteração foi confirmada no perfil. |
| LocalBusiness completo | Faltam endereço comercial completo/CEP, horários do serviço e confirmação da entidade exata do perfil. Organization foi mantido e enriquecido com dados confirmados. |
| Validação em Rich Results Test | Validação local do JSON-LD não é certificação pelo teste do Google. Resultados enriquecidos nunca foram prometidos. |
| Fotos e avaliações | Exigem fotos reais e avaliações de clientes reais. Nada foi gerado como se fosse evidência real. |
| Links externos e citações | Dependem dos perfis, parceiros e diretórios administrados pelo negócio. Não compramos links nem enviamos mensagens a terceiros. |
| Validação jurídica/contratual | Exige análise das operações com benefícios e cartão de crédito, contratos, regras das bandeiras e dados do responsável. Não foi concluída por uma alteração de SEO. |
| Privacidade definitiva | Identificação jurídica do responsável, retenção dos dados do atendimento e demais procedimentos precisam ser confirmados pelo negócio. O aviso publicado descreve somente os recursos atuais. |
| CWV de campo / INP | Exigem dados de usuários reais e/ou relatório de campo. Lighthouse local utiliza TBT e não comprova INP em uso real. |
| Monitoramento mensal e consultas/CTR | Depende de acesso ao Search Console e histórico suficiente. Nenhuma rotina automática foi criada sem solicitação. |
| Novos artigos | Há páginas e dúvidas úteis nesta entrega. Publicação recorrente deve usar dúvidas reais e condições confirmadas, sem criar páginas artificiais por bairro. |
